# theorjiugovictor.github.io

Personal site of Prince Victor Orjiugo. Vite + React, deployed to GitHub Pages.

- Edit content in `src/data.ts`; styles in `src/index.css`.
- Replace the CV at `public/Prince-Victor-Orjiugo-CV.pdf`.
- `npm install`, `npm run dev` to preview, `npm run deploy` to publish to the `gh-pages` branch.
